GU-Q Daily Hotel Room Rates Catalogue — Monthly Style, One-Sheet Package

What this package does:
- Keeps the monthly-rates catalogue card style.
- Uses DAILY room rates only.
- Excludes all long-stay/monthly/yearly rows.
- Uses one Excel/Google Sheet tab only: Catalogue_View.
- Uses uniform Record IDs in the CAT-001, CAT-002, CAT-003 format.
- Folds additional contract details into the amenities/details sections so the card view stays clean.

Files:
- index.html: website page
- styles.css: monthly-style design
- app.js: daily-rate catalogue logic
- sample-data.js: preview data from the contracts
- config.js: paste your Apps Script /exec URL here
- Code.gs: Google Apps Script API for the one-sheet Catalogue_View
- daily_rates_monthly_style_one_sheet_catalogue.xlsx: one-sheet Excel/Google Sheets template

Deployment:
1. Open the Excel file and upload/import it to Google Sheets.
2. Confirm the tab is named Catalogue_View.
3. In Apps Script, paste Code.gs.
4. Deploy as a Web App.
5. Copy the /exec URL into config.js.
6. Upload index.html, styles.css, app.js, sample-data.js, and config.js to GitHub Pages.

Important:
The uploaded contracts contain confidential/proprietary negotiated rates. Keep exact rates internal unless Finance/Procurement approves external publication.
